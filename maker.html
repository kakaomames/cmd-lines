    質問と回答

    • ゆっくりボイスメーカーとは何ですか？

      ゆっくりボイスメーカーは、入力されたテキストを「ゆっくりボイス」で読み上げるウェブアプリです。
      ウェブ上で動作するため、OSを問わず、パソコンはもちろん、スマートフォンからでも使用できます。

    • クレジット表記は必要ですか？

      いいえ、クレジット表記は任意です。
      もしもクレジット表記をいただける場合、YouTubeでは#ゆっくりボイスメーカー作品のタグを、ニコニコ動画ではnc440841を親作品にご登録いただけると嬉しいです。
      （本アプリの「最近の作品」に表示されます）

    • AquesTalkのライセンスについて質問したいです

      大変申し訳ございませんが、当方では対応できません。
      お手数ですが、AquesTalkのライセンスに関するご質問は株式会社アクエストのFAQなどを確認のうえ、それでも分からない場合は当方ではなく、株式会社アクエストへのお問い合わせをお願いいたします。

    • Scratchでも使用できますか？

      こちらの記事が参考になるかと思います。

    • 使い方を教えてください

      「テキスト」に読み上げさせたい文章を入力し、お好みで声を調整してから「再生」ボタンを押してください。
      「保存」ボタンを押すと、生成された音声をmp3ファイルとして保存できます。

    • 料金を教えてください

      ゆっくりボイスメーカー自体は完全無料でご利用いただけます。
      ただし、ゆっくりボイスメーカーは株式会社アクエストの音声合成ライブラリであるAquesTalkを使用しているため、個人利用以外の目的で利用する場合はAquesTalkの使用ライセンスが必要となります。

    • 搭載しているライブラリを教えてください

      ゆっくりボイスメーカーは以下のライブラリを搭載しています。

      • AquesTalk1 Linux Ver.1.7
      • AquesTalk1 Linux Ver.2.0
      • AquesTalk2 Linux Ver.2.3
      • AquesTalk10 Linux Ver.1.1
      • AqKanji2Koe Linux Ver.4.1

    • Discordでも使用できますか？

      はい、Discordではゆっくりボイス読み上げbotという読み上げbotを提供しております。
      ゆっくりボイス読み上げbotは、Discordに送信されたメッセージをゆっくりボイスで読み上げるbotです。

    • 使用可能なOSを教えてください

      ゆっくりボイスメーカーは最新のブラウザが動作する環境であればOSを問わず使用できます。

      以下に簡易的な動作確認を行ったOSを示しますが、これら以外のOSでもブラウザが動作する環境であれば使用できる可能性があります。
      推奨のブラウザはGoogle ChromeおよびSafariです。

      • Windows
      • macOS
      • iOS (iPhone, iPad)
      • Android

    • 「サーバーで通信エラーが発生しました」というエラーが発生します

      このエラーが発生する場合、ゆっくりボイスメーカー側で障害が発生している可能性があります。
      発生時は復旧を急ぎますが、しばらく時間を置いてから再度お試しいただくか、ゆくも！などの同様のサービスをご利用ください。

    • 「ゆくも！」が開けません

      大変申し訳ございませんが、ゆくも！はゆっくりボイスメーカーとは別のサービスであり、運営者も異なるため、こちらでは対応できません。

    • お問い合わせはどこからできますか？

      ゆっくりボイスメーカーそのものに関するお問い合わせはsiyukatu@gmail.com、公式Discordサーバー、公式Xアカウント（DMは返信が遅れる場合があります）まで、AquesTalkのライセンスに関するお問い合わせは株式会社アクエストのお問い合わせまでお願いいたします。
